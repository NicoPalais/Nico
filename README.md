# Qué tal — web en construcción

Una landing page responsive para anunciar que la web está en construcción. Incluye una ilustración animada, un interruptor de modo claro/oscuro (la preferencia se guarda en el navegador) y soporte para reducir movimiento.

## Cómo verla

Abre `index.html` en el navegador o sirve el directorio con cualquier servidor estático, por ejemplo:

```bash
python3 -m http.server 8000
```

No requiere dependencias ni proceso de compilación.
